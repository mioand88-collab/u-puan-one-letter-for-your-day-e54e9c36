Entry for the make.fun bounty "One Letter for Your Day". `main.ts` writes exactly one letter — **Z**, for *zero sleep* — to `/output/entry.txt`: a single byte, no newline. It validates the letter is one A–Z character before writing, reads the output directory from `MAKEFUN_OUTPUT_DIR` (default `/output`), and creates it if needed. No network, no secrets, nothing outside the repo.

## Run it

```sh
node main.ts
```
